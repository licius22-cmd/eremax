# Imagens do QUIZ — `quiz/images/`

Padrão de nome `stepX-N` (etapa X, foto N). Enquanto um arquivo não existir, aparece a ilustração padrão.
Os caminhos ficam em `quiz/js/config.js` → `quiz.images`.

| Etapa | Arquivo | Dica |
|---|---|---|
| 1 – Idade | `step1-1.webp` (20-29) … `step1-6.webp` (70+) | **fundo transparente** (PNG/WebP), senão o cartão não fica todo dourado ao selecionar |
| 2 – Frustração | `icons/step2-1.png` … `icons/step2-6.png` | ícones de linha pretos, fundo transparente |
| 7 – Prova social | `step7-1.webp`, `step7-2.webp`, `step7-3.webp`, `step7-4.png` | quadradas, até ~250 KB cada |
| 11 – Motivacional | `step11-1.webp` | mínimo 700px de largura |
| 14 – Resumo | `step14-1.webp` | fundo transparente ou branco |
| Logo (opcional) | `logo.png` + `quiz.images.logo` no config | 28px de altura |
