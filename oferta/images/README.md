# Imagens da OFERTA — `oferta/images/`

Enquanto um arquivo não existir, aparece a ilustração padrão. Os caminhos ficam em `oferta/js/config.js` → `oferta`.

| Seção | Arquivo | Dica |
|---|---|---|
| Galeria (topo) | `product-1.webp` … `product-4.webp` | quadradas, 1200×1200 — a 1ª é a principal |
| Pacotes | `bundle-1.webp`, `bundle-3.webp`, `bundle-5.webp` | 1, 3 e 5 unidades, fundo transparente |
| Información nutricional | `supplement-facts.png` | rótulo "Supplement Facts" |
| "Es para ti si…" | `right-for-you.webp` | horizontal 4:3 (antes/depois) |
| Ingredientes | `ingredient-1.png` … `ingredient-6.png` | fundo transparente, na ordem do config |
| Reseñas (opcional) | `review-1.jpg` … | só com avaliações reais (campo `photo` em `oferta.reviews`) |
| Especialista (opcional) | `expert.jpg` | só se configurar `oferta.expert` |
| Logo (opcional) | `logo.png` + `oferta.logo` no config | 28px de altura |
